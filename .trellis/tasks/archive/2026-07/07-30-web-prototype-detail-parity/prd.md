# 还原 Web 原型细节

## Goal

逐页核对 Open Design 项目 `5eacec88-a8bf-47bc-9795-da9afcf96465` 与当前 `apps/web`，补齐昨天 Web 原型实现遗漏的视觉、布局、交互和素材细节，使现有 Next.js / React 页面在主要桌面端和移动端视口下尽量忠实于原型，同时保留已经接入的业务能力。

`/Users/wuwanzhu/Library/Application Support/Open Design/namespaces/release-stable/data/projects/5eacec88-a8bf-47bc-9795-da9afcf96465`

## Confirmed Facts

- 昨天已经完成 Web 路由和主要页面结构，当前生产路由包括 `/`、`/chats`、`/chats/[kind]/[id]`、`/friends`、`/friends/[id]`、`/settings` 和 `/auth/callback/github`。
- 当前实现使用 Next.js 16、React 19、TypeScript、App Router、pnpm workspace 和 Turborepo；本任务继续修改 `apps/web`，不另建工程。
- 原型目录没有 `DESIGN.md`、`README` 或 `package.json`。设计依据是 7 个 HTML、7 个 artifact JSON、`assets/moodmate.css`、`brand-spec.md` 和 `docs/*.md`。
- 原型没有位图、视频或字体素材；头像使用固定渐变和首字，图标使用 lucide 风格线性图标。
- 原型默认暗色，提供亮色；当前工程使用 `mocha` / `latte` 主题契约，不能复制原型的 `light` / `dark` 主题运行时。
- 原型应用壳的桌面布局基线是 72px 导航栏、340px 列表栏、自适应主区和可选 300px 信息栏；主要断点是 1100px、820px 和 640px。
- 昨天的实现已经接入真实 API。细节还原不能破坏登录、单聊、群聊、朋友管理、记忆、主动关怀和主题持久化。
- 当原型实际渲染与 class 名或可推断的设计意图冲突时，以浏览器中的实际渲染为验收依据。例如 `agent-detail.html` 的 `grid-3` 没有对应 CSS，统计卡按原型实际效果还原为三张纵向通栏卡。

## Requirements

- 逐页核对 `login.html`、`chat-single.html`、`chat-group.html`、`contacts.html`、`agent-detail.html` 和 `settings.html` 与对应 React 页面。
- 以原型 HTML、共用 CSS、artifact JSON 和设计文档中的具体值为依据，核对尺寸、间距、排版、颜色、边框、圆角、阴影、层级、溢出和响应式行为。
- 核对并补齐原型可演示的菜单、弹层、会话切换、信息栏显隐、输入框自动增高与键盘发送、筛选、设置面板、开关和主题切换。
- 单聊补齐日期分隔、历史消息时间、连续消息样式、三点输入状态、复制按钮和输入区工具入口；`createdAtMs` 必须从现有合同保留到展示层。
- 群聊补齐日期分隔、连续消息样式、等待回复状态、消息操作和输入区工具入口，不能破坏 @ 候选、成员管理和发送能力。
- 把原型的朋友头像点击/右键菜单接入聊天头与消息头像，继续使用现有菜单边界检测和关闭行为。
- 补齐单聊与群聊信息栏中的原型分组和操作位置；缺少后端合同的操作使用 disabled 或静态状态，不发起无效请求。
- 通讯录卡片恢复整卡可进入详情和两行描述密度，同时保留编辑、暂别和查看详情操作。
- 设置页主题预览卡可直接选择 Latte / Mocha；通用、记忆和主动关怀继续保留现有真实能力。
- 保持现有路由、真实数据接入和业务能力；只修改与本轮原型细节还原直接相关的代码。
- 复用原型已有素材表现和 `lucide-react` 图标，不自行添加无依据的插图或装饰。
- 对无法直接照搬的静态示例与真实数据差异，优先保持真实功能，再用现有组件结构还原视觉状态。
- 视觉验证覆盖主要桌面端和移动端视口，并检查主题、交互、控制台错误和资源加载。
- 不修正原型自身未生效的 class 或推测性设计；只要原型实际效果稳定可见，就按实际效果实现。

## Acceptance Criteria

- [ ] 六个用户页面与原型逐页核对，审计结果记录具体差异和对应文件位置。
- [ ] 桌面端应用壳、聊天区、朋友页、详情页、设置页和登录页的关键尺寸与原型一致。
- [ ] 1100px、820px、640px 附近的布局变化与原型一致，不出现文字、控件或面板重叠。
- [ ] 原型中可操作的菜单、弹层、输入框、筛选、面板、开关和主题交互在 React 页面中可用。
- [ ] 单聊历史消息显示合同中的时间，跨日显示日期分隔，连续消息不重复占用头像位置。
- [ ] 单聊生成和群聊等待回复时显示原型三点状态，完成或失败后状态消失。
- [ ] 单聊与群聊消息可复制，复制按钮不改变现有赞同、反对和发送流程。
- [ ] 聊天头与消息中的朋友头像支持点击和右键菜单，菜单在视口边缘不溢出。
- [ ] 单聊与群聊信息栏恢复原型的头部操作与内容分组，真实成员管理仍可使用。
- [ ] 主题预览卡可直接切换 Latte / Mocha，刷新后继续使用现有主题持久化结果。
- [ ] 暗色和亮色页面均完成截图核对；头像、图标、状态点、气泡和主题素材表现与原型一致。
- [ ] 朋友档案统计区在基准桌面视口下显示为三张纵向通栏卡，与原型实际渲染一致。
- [ ] 当前真实登录、单聊、群聊、朋友管理、记忆和主动关怀能力没有回归。
- [ ] 浏览器控制台没有新增运行错误、hydration warning 或资源加载错误。
- [ ] 按顺序通过 `pnpm check-types`、`pnpm lint`、`pnpm format:check`，并通过 `pnpm --filter web build`。
- [ ] `pnpm dev:web` 可在 `http://localhost:6153` 启动并完成页面预览。

## Out of Scope

- 不修改 API、数据库、contracts、Admin 或共享主题包。
- 不新增 OAuth、头像上传、消息免打扰、群设置或资料保存接口。
- 不把原型示例统计写入后端，也不让静态控件伪装成保存成功。
- 不新增 Playwright 或其他测试依赖。
