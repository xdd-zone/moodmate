# 实现通讯录与朋友档案路由

## Goal

按 `contacts.html` 和 `agent-detail.html` 实现新的朋友列表与朋友详情路由。

## Requirements

- `/friends` 按 `contacts.html` 重构通讯录，继续读取真实朋友列表。
- 保留新建、编辑和删除朋友能力，并把现有表单放入原型弹层视觉。
- 支持名称搜索和原型页签筛选；筛选只处理当前已加载数据。
- 新增 `/friends/[id]`，按 `agent-detail.html` 展示朋友资料。
- 详情页从现有朋友数据读取名称、简介、描述和可用字段；没有合同的统计、故事和约定使用静态占位。
- 加载、空列表、接口失败、朋友不存在和删除后返回都有明确页面状态。

## Acceptance Criteria

- [ ] 通讯录网格、页头、筛选、朋友卡片和操作按钮与原型一致。
- [ ] 真实朋友可创建、编辑、删除和打开详情。
- [ ] `/friends/[id]` 可直接访问，朋友不存在时不会渲染错误档案。
- [ ] 档案页桌面和移动端可完整滚动，长文本不溢出。
- [ ] 质量命令和 Web build 通过。
